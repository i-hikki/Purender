# scene.md

Satu nomor = satu scene = satu video. Dikerjakan berurutan dari nomor terkecil yang `status= belum`.
Agent hanya boleh mengubah baris `status=`. Selebihnya ditulis user.

Format:

```
## N. Judul (opsional)
durasi= detik (opsional, bila kosong ambil dari promp)
promp= detail scene: tokoh, gerak, suasana, warna, kamera
mp3= dialog/narasi yang akan direkam atau di-dubbing user di editor
reff= ref/nama_file.png atau ref/nama_file.md (opsional)
status= belum | selesai
```
